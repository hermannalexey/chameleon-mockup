# Chameleon — Mockup

Clickable front-end prototype for **Chameleon**, a task-management app (an Asana-style tool).
This is a design mockup only: no backend, no accounts — task data resets on refresh. It exists to align on the look and flow of the core screens before the real app is built.

## Views
- **My Tasks** — your tasks across projects, grouped by due date.
- **Board** — kanban with drag-and-drop between columns.
- **List** — project tasks grouped by section.
- **Task drawer** — assignee, due date, priority, subtasks, comments.

Sample data is illustrative only.

## Run locally
Open `index.html` in any browser. No build step.
